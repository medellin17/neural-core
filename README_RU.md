## О проекте

**NEURAL CORE** — это экспериментальный веб-опыт, который придерживается философии "Сырого кода". Каждый визуальный элемент генерируется программно в реальном времени:

- **ASCII-арт** — 3D-сферы, отрисованные как анимированные символы
- **WebGL** — нейронные сети с тысячами связей
- **Canvas** — живые потоки данных, спарклайны и терминальная эстетика

## Опыт использования

### Главный экран (Hero)
- Вращающаяся 3D-сфера, отрисованная в реальном времени как ASCII-символы
- Анимация scramblе-текста при наведении
- Терминальные состояния загрузки

### Модальное окно архитектуры
- Интерактивная 3D-визуализация нейронной решётки
- 19 узлов × 46 связей с анимированными пакетами данных
- Перетаскивание для вращения, прокрутка для масштабирования
- Сетка для технической эстетики

### Панель метрик
- Живые ASCII-спарклайны: `_ . - ^ ~`
- Блочные гистограммы: `█ ▓ ▒ ░`
- Мерцающие индикаторы статуса
- Водопадные анимации данных
