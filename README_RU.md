# NEURAL CORE

> **ФУНДАМЕНТАЛЬНЫЙ ИНТЕЛЛЕКТ**

Бруталистичный лендинг, где сырой код превращается в визуальный опыт.
Без изображений. Без видео. Только алгоритмы, рисующие на холсте.

## ВИЗУАЛЬНЫЙ ОПЫТ

**NEURAL CORE** — это эксперимент: что произойдёт, если код откажется быть невидимым?
Когда алгоритмы станут искусством, а каждый пиксель будет вычислен в реальном времени.

Страница разворачивается как путешествие через пять визуальных языков:

---

### 01 │ HERO ◉◉◉

**250 синих сфер дрейфуют по холсту**, очерчивая невидимые пути в ландшафте Perlin-шума.
Каждая частица следует математическому потоку — пока ваш курсор не вступает в игру.
Тогда он становится гравитационной ямой, притягивая рой в орбиту.

◉ Частица улетает вправо → появляется слева. Вечный цикл.

```
Технология: p5.js (instance mode)
Алгоритм:   Perlin noise flow field + притяжение мыши
```

---

### 02 │ METRICS ░░▓▓█

Визуализации данных, полностью состоящие из текста:

```
Спарклайн: _ . - ^ ~ - . _ . - ^
           [-2 -1  0  1  2  1  0 -1]

Bar-чарт:   [██████████░░░░░░░░]  67%
```

Каждый график. Каждый индикатор. Чистый ASCII. Без изображений.

```
Технология: Манипуляция строк + Unicode block-символы
```

---

### 03 │ ARCHITECTURE ●───●

3D нейронная решётка из 17 узлов в 5 слоях:

```
    INPUT_LAYER    ●───●───●
                       ║
    HIDDEN_1     ●───●───●───●
                  ║   ║   ║   ║
    HIDDEN_2     ●───●───●───●───●
                  ║   ║   ║   ║
    HIDDEN_3     ●───●───●───●
                       ║
    OUTPUT         ●───●───●
```

Светящиеся импульсы путешествуют по 39 путям. Перетаскивайте для вращения.
Прокручивайте для масштабирования.

```
Технология: React Three Fiber + drei (WebGL)
Рендеринг:  Стандартный 3D (не ASCII)
```

---

### 04 │ FLOW ◉────────◉

35 частиц дрейфуют в пространстве. Когда две сближаются, между ними возникает нить —
синаптический мост, формирующийся и растворяющийся.

```
    ◉───────◉          ◉───────◉
     ╲     ╱            ╲     ╱
      ╲   ╱              ╲   ╱
       ╲ ╱                ╲ ╱
        ◉                  ◉
```

Визуализация эмерджентной связности в стиле TouchDesigner.

```
Технология: Чистый Canvas API
Алгоритм:   Динамические соединения по расстоянию
```

## ЭСТЕТИКА

**NEURAL CORE** черпает из двух визуальных традиций:

```
КОРЕЙСКИЙ МИНИМАЛИЗМ                ТЕРМИНАЛЬНЫЙ БРУТАЛИЗМ
════════════════════                 ═════════════════════

• Чистые линии                      • Моноширинная типографика
• Абсолютная точность               • ASCII-арт
• Whitespace как элемент            • Командная строка
• Сетка празднуется                 • Сырые потоки данных
• Без визуального шума              • Машина видна

                    ║
                    ║
                    ▼

          КИБЕРПАНК-МИНИМАЛИЗМ
          ─────────────────────

     Пересечение

     Футуристичное + Ностальгия
     AI из другой временной линии
```

## ЖИВОЙ ОПЫТ

Статичные скриншоты не могут передать суть. Это нужно видеть в движении:

- Дрейф 250 частиц сквозь Perlin-шум со скоростью 60fps
- Курсор мыши как гравитационная яма для роя
- Вечный цикл — улетели вправо, появились слева
- Светящиеся импульсы на 39 нейронных путях
- Эмерджентные соединения в сети частиц
- Прокручивающаяся загрузка, оживляющая машину
