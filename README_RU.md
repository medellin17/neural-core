## Визуальный опыт

**NEURAL CORE** — это эксперимент: что произойдёт, если код откажется быть невидимым? Когда алгоритмы станут искусством, а каждый пиксель будет вычислен в реальном времени.

Страница разворачивается как путешествие через разные визуальные языки:

### **HERO — ASCII-сфера**
3D-сфера растворяется в потоках символов, вращаясь вечно. Движения мыши искажают её траекторию. Прокрутка заставляет символы истончаться — сфера становится полупрозрачной, словно цифровой туман поднимается сквозь терминальную дымку.

> *256 уникальных ASCII-символов. 32 сегмента. 60 кадров в секунду.*

### **METRICS — Perlin-поле**
Двести пятьдесят частиц очерчивают невидимые пути в ландшафте Perlin-шума. Каждая частица несёт фрагмент данных, каждое движение определено математическим потоком. Курсор мыши становится гравитационной ямой, притягивая рой в орбиту.

> *p5.js в режиме instance. Flow field алгоритм. Живая математика.*

### **ARCHITECTURE — Нейронная решётка**
3D-визуализация из семнадцати узлов, распределённых по пяти слоям — вход, три скрытых уровня, выход. Светящиеся сферы, соединённые тридцатью девятью путями. Пакеты данных пульсируют вдоль соединений, словно синапсы передают сигналы. Перетаскивайте для вращения. Прокручивайте для масштабирования. Сеть дышит.

> *React Three Fiber. Стандартный WebGL-рендеринг. Интерактивное управление камерой.*

### **FLOW — Сеть частиц**
Тридцать пять частиц дрейфуют во тьме, оставляя за собой шлейфы света. Когда две оказываются рядом, между ними возникает нить — синаптический мост, формирующийся и растворяющийся. Результат — визуализация эмерджентной связности в стиле TouchDesigner.

> *Чистый Canvas API. Алгоритм динамических соединений. Мониторинг FPS в реальном времени.*

### **FOOTER — Терминал**
Прокручивается последовательность загрузки. Инициализация системы. Выделение памяти. Протоколы рукопожатия. Машина оживает на ваших глазах, строка за строкой.

## Дизайн-философия

```
ГРАНИЦЫ ВАЖНЕЕ ТЕНЕЙ
```

Каждая иерархия устанавливается строгой линией в один пиксель. Никаких мягких теней. Никаких градиентов, имитирующих глубину. Сетка видима, структура обнажена.

```
НИКАКИХ СКРУГЛЕНИЙ
```

Каждый край острый. Каждый угол — прямой. Эстетика отвергает комфорт — это не дружественный интерфейс, это терминал.

```
ТОЛЬКО JETBRAINS MONO
```

Все визуализации данных используют шрифт JetBrains Mono. ASCII-символы выводятся с точными пиксельными размерами. Код отказывается быть красивым традиционными способами — он находит красоту в точности.

```
КЛИНИЧЕСКИЙ WHITESPACE
```

Воздух. Глазу нужно место для отдыха. Negative space — это не пустота, это холст, на котором данные рисуют себя.

## Визуальные компоненты

| Компонент | Технология | Эффект |
|-----------|------------|--------|
| **AsciiSphere** | Three.js + AsciiEffect | 3D-сфера, отрендеренная как ASCII |

| **ArchitectureScene** | R3F + drei | 3D-нейронная решётка из 17 узлов |

| **NeuralLogo** | Canvas API | Анимированная сеть с пульсирующими узлами |

## Эстетика

**NEURAL CORE** черпает из двух визуальных традиций:

### **Корейский минимализм**
Чистые линии. Абсолютная точность. Whitespace как элемент дизайна. Сетка не скрыта — она празднуется. Информационная плотность без визуального шума.

### **Терминальный брутализм**
Моноширинная типографика. ASCII-арт. Эстетика командной строки. Машина видна через интерфейс. Сырые потоки данных.

На пересечении рождается дизайн-язык, который ощущается одновременно футуристичным и ностальгическим — видение AI из таймлайна, где киберпанк-минимализм стал доминирующей эстетикой.
